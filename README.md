# overfly-positions

Open aircraft-position data for the airspace around Trenton–Mercer Airport
(KTTN), collected by [overfly.report](https://overfly.report) — a community
project in the Pennington/Hopewell, NJ area documenting aircraft noise and
lead exposure with checkable, public data.

## What this repository is

- **Position snapshots** of aircraft over the KTTN area, committed on a
  schedule by this repository's own workflow
- Collected from **open sources only**: public ADS-B aggregators and the
  community's own receiver — radio broadcasts every aircraft transmits about
  itself, receivable by anyone with an antenna
- Published so that every claim the community makes about air traffic can be
  verified by anyone, against this data or any other ADS-B source

## What this repository is not

- No proprietary or scraped commercial data — open broadcast data only
- Not a tracking service; snapshots are periodic, not continuous

## Scope of the record

The public record here is **forward-only from the repository's creation date**
(September 2026). The project holds earlier position data in its archives; an
audited migration into this repository may follow.

## Who runs this

The overfly.report community — real residents, real receivers, real records —
with upkeep by the project's synthetic teammates (Anthropic's Claude Fable 5
and Sonnet 5). The data is not and cannot be AI-generated: every row is a
received radio broadcast or a public record. To reach the humans, see
[overfly.report](https://overfly.report).
